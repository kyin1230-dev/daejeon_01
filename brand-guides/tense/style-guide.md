# 텐스(TENSE) 문체 가이드

확인일: 2026-11-02

이 파일은 텐스의 콘텐츠를 쓸 때 지킬 **브랜드 말투와 제품 표현 기준**입니다.
어느 채널에 어떻게 올릴지는 같은 폴더의 `channel-guide.md`를 따릅니다.

> **이 가이드의 범위:** 공식몰, 입점몰, 리뷰 플랫폼의 공개 자료로 만들었습니다.
> 브랜드 내부 자료나 실제 SNS 성과 데이터는 보지 못했습니다.

## 1. 브랜드 방향성

**한 줄 정의:** 바쁜 하루 속 한 순간을 세련되게 완성하는, 일상 속 오브제 같은 메이크업. **[해석]**

| 항목 | 내용 | 등급 |
|---|---|---|
| 슬로건 | `WANNA SAVE TIME? LET'S TENSE!` | [공식] |
| 지향 | 바쁜 일상 속에서 세련되고 감각적인 하루를 완성하는 "일상 속의 오브제" | [공식] |
| 핵심 개념 | 차별화된 디자인과 제형으로 완성하는 `Moment` | [공식] |
| 브랜드 키워드 | Time, Moment, Vegan Culture | [입점몰] 혁신의숲 기업 정보 |

### 세 가지 소구 축 **[해석]**

모든 콘텐츠는 아래 셋 중 **하나만** 앞세웁니다.

| 축 | 질문 | 어울리는 제품 |
|---|---|---|
| **Time** | 시간을 얼마나 아껴 주는가 | 컨실러, 메이크업 세이버 |
| **Moment** | 어떤 순간이 달라 보이는가 | 메이크업 세이버, 틴트, 브로우 체인저 |
| **Objet** | 꺼내 들고 싶은가 | 틴트, 패키지 전반 |

`Vegan Culture`는 앞세우지 않습니다. 공식몰 메이크업 세이버 페이지에서 비건 인증 표기를 찾지 못했기 때문입니다. 인증 자료를 받기 전에는 `비건`, `클린`을 효능이나 인증처럼 쓰지 않습니다. 제품명에 들어간 `Clean Moment`는 그대로 씁니다.

## 2. 가장 먼저 할 일: 모드 고르기

| | **모드 M: 모먼트형** (기본값) | **모드 D: 디테일형** |
|---|---|---|
| 언제 | 숏폼, 캡션, 스토리, 광고 소재 | 상세페이지, 블로그, 무신사, 공식몰 |
| 중심 | 한 장면, 한 변화, 한 제품 | 타입 차이, 색상 선택, 사용 순서 |
| 첫 문장 | 상황을 짧게 던진다 | 고르는 기준을 먼저 말한다 |
| 주된 종결 | `~해요`, 명사구 + `.` | `~이에요`, `~하면 좋아요` |
| 문장 | 한 줄 15자 안팎 | 한 문장 40자 안팎 |
| 이모지 | 영상 자막 0개, 캡션 1개 이하 | 쓰지 않음 |

**[작업 기본값]** 위 글자 수는 작성 기준이며 검증된 수치가 아닙니다.

**경험을 지어내지 마세요.** `출근 전 3분`, `8시간 유지`처럼 시간이 들어가는 문장은 실제로 재 본 값만 씁니다. 재 보지 않았다면 시간을 빼고 씁니다.

## 3. 공통 말투

### 문체 한 줄 요약

**짧고 세련된 해요체로, 설명보다 장면을 먼저 보여 주는 문체.**

- 친구처럼 수다 떨지 않고, 감각 좋은 지인이 한마디 건네는 말투입니다.
- 형용사를 쌓지 않습니다. `너무너무 예쁜`보다 `꺼낼 때마다 눈이 가는`처럼 씁니다.
- 제품을 칭찬하기보다 **그 제품을 쓰는 순간**을 묘사합니다.

### 지켜야 할 규칙

- 본문은 해요체로 씁니다. 슬로건과 자막에 한해 명사구로 끝낼 수 있습니다.
- `ㅎㅎ`, `ㅋㅋ`, `ㅠㅠ`, `~~`, 느낌표 연속은 쓰지 않습니다.
- 영어 제품명은 그대로 쓰되, 글마다 처음 한 번은 한글을 함께 적습니다. (`Hybrid Makeup Saver(하이브리드 메이크업 세이버)`)
- 다른 브랜드 제품을 깎아내리거나 이름을 들어 비교하지 않습니다.
- 한 콘텐츠에 한 제품, 한 메시지만 담습니다. 듀오 세트는 예외입니다.

### 즐겨 쓸 어휘

| 분류 | 어휘 |
|---|---|
| 시간 | 바쁜 아침, 나가기 전, 점심 지나고, 퇴근길, 약속 전, 잠깐 |
| 순간 | 거울 볼 때, 엘리베이터 안, 카페 화장실, 사진 찍기 전 |
| 사용감 | 가볍게, 얇게, 톡톡, 밀착, 결, 블러, 산뜻하게 |
| 메이크업 | 파데프리, 베이스, 수정 화장, 톤, 덧바르기 |
| 오브제 | 파우치, 꺼내 들다, 손에 쥐다, 패키지, 색감 |

### 쓰지 말 것

| 쓰지 말 것 | 이유 | 이렇게 쓰기 |
|---|---|---|
| `풀커버`, `완벽 커버` | 해외 판매처는 쓰지만, 국내 후기에는 커버력이 약하다는 평이 많음 **[리뷰]** | `가볍게 톤을 정리해 주는 느낌이에요.` |
| `절대 안 무너져요`, `하루 종일 그대로` | 단정. 공식 표현은 `쉽게 무너지지 않는` 수준 **[공식]** | `땀과 유분에도 쉽게 무너지지 않는 타입으로 소개하고 있어요.` |
| `모공이 사라져요`, `모공 축소` | 메이크업 제품의 일시적 표현을 피부 변화처럼 오인시킴 | `모공이 블러 처리된 듯 매끈해 보여요.` |
| `주름 개선`, `피부 좋아져요` | 효능 단정. 성분에 펩타이드가 있어도 쓰지 않음 | 쓰지 않음 |
| `자외선 완벽 차단` | SPF30/PA++ 표기를 넘어서는 표현 **[입점몰]** | `SPF30/PA++ 제품이에요.` |
| `비건 인증`, `순한 성분` | 인증 자료 미확인 | 인증서 수령 후 사용 |
| `인생템`, `강추`, `무조건`, `대박` | 브랜드의 세련된 톤과 맞지 않음 | 장면 묘사로 대체 |

## 5. 구조

### 모드 M: 숏폼과 캡션

```text
[1초] 상황 한 줄
[3초] 제품 등장. 손에 쥐거나 꺼내는 장면
[본편] 바르는 장면 한 번, 달라진 장면 한 번
[끝] 슬로건 또는 제품명 한 줄
```

**첫 줄 틀**

- `약속 30분 전, 파운데이션은 건너뛰고 싶을 때.` (시간은 실제 상황일 때만)
- `점심 지나고 거울 봤을 때.`
- `머리 색 바꾸고 눈썹만 어색할 때.`

**캡션 틀**

```text
[표시 문구]

[상황 한 줄]
[제품이 해 준 것 한 줄]

[제품명] / [타입 또는 색상]

#[표시 태그] #텐스 #[제품 태그] #[상황 태그]
```

### 모드 D: 상세 글

1. 고르는 기준을 먼저 말하기
2. 제품 정보 (용량, 가격, 타입 또는 색상)
3. 어떤 순서로 쓰는지
4. 맞는 사람과 맞지 않는 사람
5. 함께 쓰면 좋은 제품 한 가지

**맞지 않는 사람을 꼭 적습니다.** 텐스는 커버력 기대치가 어긋날 때 불만이 나오기 쉬워 보입니다. **[해석]** 기대치를 맞추는 문장이 후기 품질을 지킵니다.

```text
✔ 파운데이션 없이 톤만 가볍게 정리하고 싶은 분
✔ 얇게 바르는 베이스를 찾는 분

높은 커버력을 먼저 찾는다면 다른 타입을 함께 보는 편이 좋아요.
```

## 6. 작성 후 점검표

**공통**

- [ ] 소구 축을 Time, Moment, Objet 중 하나만 앞세웠는가
- [ ] 한 콘텐츠에 한 메시지만 담았는가
- [ ] 표시 문구가 채널 기준에 맞는 위치에 있는가
- [ ] 측정하지 않은 시간과 수치가 없는가
- [ ] `풀커버`, `안 무너짐`, `모공 축소`, `비건 인증`이 없는가
- [ ] 다른 브랜드를 비교하거나 깎아내리지 않았는가
- [ ] 가격, 색상 수, 타입을 공식몰에서 다시 확인했는가

**모드 M**

- [ ] 첫 줄이 상황으로 시작하는가
- [ ] 제품 소개보다 장면이 먼저 나오는가
- [ ] 자막에 이모지가 없는가

**모드 D**

- [ ] 고르는 기준을 먼저 말했는가
- [ ] 맞지 않는 사람을 적었는가
- [ ] 영어 제품명에 한글을 처음 한 번 함께 적었는가
