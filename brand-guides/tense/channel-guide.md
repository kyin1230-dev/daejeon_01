# 텐스(TENSE) 채널 가이드

확인일: 2026-11-02

이 파일은 텐스가 **어느 채널에 무엇을 올릴지** 정한 기준입니다.
말투와 제품 표현은 같은 폴더의 `style-guide.md`를 따릅니다.

> **조사 한계:** 인스타그램과 틱톡의 팔로워, 조회수, 전환 데이터는 보지 못했습니다.
> 채널 등급은 제품 특성과 공개된 판매 현황으로 내린 판단입니다. 실제 성과 데이터가 있으면 그 수치를 우선합니다.

---

## 1. 채널 선정 결론

**텐스는 눈으로 바로 보이는 메이크업 브랜드이므로, 숏폼으로 보여 주고 무신사와 공식몰에서 구매를 받습니다.**

### 선정 기준

| 기준 | 텐스의 상황 |
|---|---|
| 제품 특성 | 바르는 순간 차이가 보임. 영상이 글보다 유리 |
| 브랜드 자산 | 슬로건이 시간과 순간에 맞춰져 있어 짧은 형식에 맞음 |
| 현재 판매처 | 공식몰, 무신사, 시코르, 일본 공식몰 |
| 현재 채널 | 인스타그램, 틱톡, 유튜브, 카카오 채널 |
| 확인 못 한 것 | 올리브영 입점 여부 |

### 채널 등급

| 등급 | 채널 | 역할 | 이유 |
|---|---|---|---|
| **핵심** | 인스타그램 릴스 | 브랜드 무드, 크리에이터 협업 | 오브제 같은 패키지와 색감을 보여 주기 좋음 |
| **핵심** | 틱톡 (크리에이터 계정) | 신규 도달, 변화 장면 | 전후 차이가 뚜렷한 브로우 체인저에 맞음. 공식 계정은 비로그인 화면에 활동 수치가 없어 크리에이터 계정 게시를 전제로 함 |
| **핵심** | 무신사 뷰티 | 구매 전환, 리뷰 축적 | 세이버 후기 159개, 평점 4.5로 판매 근거가 확인됨 |
| **핵심** | 공식몰 | 세트 판매, 정기배송 | 듀오 세트와 정기배송 옵션이 있음 |
| **확장** | 일본 (공식몰 + @cosme + 일본어 숏폼) | 다음 성장 시장 | 일본 공식몰 운영, 2026-08-26~09-29 @cosme 도쿄·오사카 오프라인 진행. 공식 해시태그 `#テンスブロウ`로 브로우를 전면에 둠 |
| **보조** | 유튜브 쇼츠 | 숏폼 재활용 | 공식 채널이 있어 추가 촬영 없이 운영 가능 |
| **보조** | 네이버 블로그 체험단 | 색상, 타입 검색 대응 | `컨실러 색상`, `세이버 타입 차이` 같은 비교 수요 대응 |
| **보조** | 카카오 채널 | 재구매, 신상품 알림 | 기존 고객 대상. 신규 유입용이 아님 |
| **보류** | 페이스북 | - | 젊은 메이크업 고객과 맞는 근거를 찾지 못함 |
| **보류** | 올리브영 콘텐츠 | - | 입점 확인 후 재검토 |

## 2. 운영 기준

아래 주기와 비율은 **[작업 기본값]** 입니다. 한 달 운영 후 실제 수치로 조정합니다.

| 채널 | 주기 | 모드 | 볼 지표 |
|---|---|---|---|
| 인스타그램 릴스 | 주 2~3회 | M | 저장, 공유, 프로필 방문 |
| 틱톡 | 주 3회 | M | 끝까지 본 비율, 공유 |
| 유튜브 쇼츠 | 릴스 재활용 | M | 조회수 |
| 무신사 | 상시 | D | 전환율, 후기 수, 평점 |
| 공식몰 | 상시 | D | 세트 구매 비중, 정기배송 전환 |
| 네이버 블로그 | 월 4~8건 | D | 검색 유입 |
| 카카오 채널 | 월 2회 이내 | D | 클릭, 쿠폰 사용 |

### 콘텐츠 비중

| 유형 | 비중 | 예 |
|---|---|---|
| 상황 해결 | 50% | 점심 후 수정 화장, 파데프리 베이스 |
| 변화 장면 | 30% | 탈색모 눈썹 색 바꾸기 |
| 무드와 오브제 | 20% | 파우치, 색상 모음 |

## 3. 인스타그램 릴스

- **길이:** 15~30초 **[작업 기본값]**
- **첫 장면:** 얼굴 인사가 아니라 상황으로 시작합니다.
- **촬영:** 자연광 근접 촬영을 기본으로 하고, 피부 보정 필터를 쓰지 않습니다. 메이크업 제품의 변화 장면에 과한 보정이 들어가면 실제와 다르게 보일 수 있기 때문입니다.
- **자막:** 소리를 꺼도 뜻이 통하게 넣습니다.
- **커버:** 제품과 상황이 한 장면에 보이게 합니다.
- **음악:** 상업적으로 쓸 수 있는 음원인지 확인합니다.

### 시리즈 제안 **[해석]**

| 시리즈 | 내용 | 제품 |
|---|---|---|
| `Save Time` | 나가기 전 베이스를 얼마나 줄였는지 실측 | 듀오 세트 |
| `Moment Check` | 점심, 퇴근길 같은 시간대별 거울 장면 | 세이버 |
| `Brow Change` | 머리색별 눈썹 색 맞추기 | 브로우 체인저 |
| `In My Pouch` | 파우치 속 오브제 | 틴트, 컨실러 |

## 4. 틱톡

- **길이:** 15~30초 **[작업 기본값]**
- **원칙:** 릴스를 그대로 옮기지 않습니다. 틱톡은 더 직접적으로 찍습니다.
- **첫 2초:** 변화가 시작되는 장면을 먼저 보여 줍니다.
- **형식:** 세로 얼굴 근접, 한 번에 찍은 듯한 장면.
- **크리에이터 조건:** 팔로워 수보다 실제 메이크업 과정을 보여 주는 사람을 고릅니다.

## 5. 무신사와 공식몰

- 상세 소개는 `style-guide.md`의 모드 D로 씁니다.
- 세이버는 타입 차이를 표 하나로 정리합니다.
- 컨실러는 5색을 같은 조명에서 찍은 비교 이미지를 넣습니다. 후기에서 색상 불만이 나오므로 구매 전에 정보를 주는 쪽이 낫습니다.
- 후기 이벤트는 대가 제공 사실을 후기에 표시하게 안내합니다.
- 무신사 남성 부문 순위가 확인되므로 남성 고객용 소재를 한 번 시험합니다. **[해석]**

## 6. 일본 확장

일본 공식몰은 한국 발송 안내가 붙어 있고, 제품은 ¥2,350~¥3,450 범위입니다.

**확장 순서 [해석]**

1. 일본어 상세 설명을 현지 표현으로 다시 씁니다. 번역만 하지 않습니다.
2. 일본 크리에이터 2~3명과 소규모로 시험합니다.
3. @cosme 오프라인 이후의 입점 현황을 브랜드에 확인하고, 일본 콘텐츠의 주력을 브로우 체인저로 둡니다.

**일본 표시 규칙**

- 일본은 2023년 10월부터 대가를 받은 게시물에 `PR`, `広告` 같은 표기가 없으면 부당 표시로 봅니다. 해설 자료 기준이며 소비자청 원문은 직접 확인하지 못했습니다.
- 책임은 광고주에게 있다는 해설이 있으므로 브랜드가 게시물을 직접 점검합니다.
- 일본의 화장품 표현 규제(약기법)는 이번에 확인하지 못했습니다. 일본어 원고는 현지 전문가 검수 후 게시합니다.

## 7. 광고 표시 규칙

공정위 추천·보증 지침을 다룬 기사와 해설을 정리했습니다. **최신 개정은 공정위 원문으로 확인해야 합니다.**

| 항목 | 기준 |
|---|---|
| 표시 대상 | 현금, 제품 제공, 할인, 협찬 등 경제적 이해관계 전부 |
| 인스타그램 캡션 | 본문 첫 부분이나 첫 번째 해시태그 |
| 사진에 표시할 때 | 모든 사진에 표시한다는 해설이 있음 |
| 영상 전체가 추천일 때 | 시작과 끝에 넣고 영상 중 반복 표시 |
| 안 되는 위치 | `더보기` 뒤, 게시물 중간, 댓글, 별도 페이지 |
| 쓸 수 있는 말 | `협찬`, `광고`, `유료 광고`, `광고비 지급` |
| 쓸 수 없는 말 | `sponsored`, `partner`, `thanks to`, `Collaboration` |

릴스에 직접 적용되는 세부 기준은 찾지 못했습니다. 그래서 아래를 작업 기준으로 정합니다. **[작업 기본값]**

- 영상 전체에 `협찬` 자막을 고정합니다.
- 캡션 첫 줄에 `#협찬` 또는 `광고`를 씁니다.
- 플랫폼의 유료 광고 표시 기능도 함께 켭니다.

## 8. 크리에이터 브리프 양식

아래는 간단한 요약 양식입니다. 실제 발송은 `guide-instagram-reels.md`, `guide-tiktok.md`를 씁니다. 크리에이터의 개성을 살리되, **표현 금지선만 분명히** 정합니다.

```text
[기본 정보]
업로드 기한:
협업 형식:
제공 제품:
표시 문구:

[이번 콘텐츠의 한 문장]
(예: 파운데이션을 건너뛰는 날의 베이스)

[꼭 담을 것 3가지]
1. 제품명과 타입 또는 색상
2. 실제 사용 장면
3. 실제로 느낀 점

[자유롭게 해 주세요]
상황, 음악, 편집, 말투

[쓰지 말아 주세요]
풀커버 / 절대 안 무너짐 / 모공 축소 / 주름 개선 / 비건 인증 / 다른 브랜드 비교

[확인 일정]
초안 제출일:
수정 회신일:
게시물 유지 기간:
```

## 9. 발행 전 점검표

- [ ] 이 채널의 역할에 맞는 콘텐츠인가
- [ ] 릴스를 틱톡에 그대로 옮기지 않았는가
- [ ] 첫 장면이 상황이나 변화로 시작하는가
- [ ] 표시 문구가 시작, 끝, 캡션 첫 부분에 있는가
- [ ] `sponsored`, `partner` 같은 표현만 쓰지 않았는가
- [ ] 필터와 보정이 제품 효과를 과장하지 않는가
- [ ] 측정한 시간만 적었는가
- [ ] 음원 사용 권리를 확인했는가
- [ ] 일본 게시물에 `PR` 표기가 있고 현지 검수를 거쳤는가
