# 케어드(kared) 채널 가이드

확인일: 2026-11-02

이 파일은 케어드가 **어느 채널에 무엇을 올릴지** 정한 기준입니다.
말투와 제품 표현은 같은 폴더의 `style-guide.md`를 따릅니다.
네이버 블로그 노출 기준은 `guides/seo-guide.md`를 그대로 따릅니다.

> **조사 한계:** 채널별 팔로워, 매출, 전환 데이터는 보지 못했습니다.
> 채널 등급은 제품 특성과 공개된 판매 현황으로 내린 판단입니다. 실제 성과 데이터가 있으면 그 수치를 우선합니다.

## 1. 채널 선정 결론

**케어드는 고민을 검색해서 찾아오는 브랜드이므로, 국내는 네이버 검색을 중심에 두고 올리브영 매장에서 체험하게 하며, 해외는 틱톡과 아마존으로 넓힙니다.**

## 3. 네이버 블로그

`guides/seo-guide.md`의 기준을 모두 따릅니다. 아래는 케어드에 맞춰 더한 내용입니다.

### 왜 잘 맞는가

네이버의 좋은 글 5원칙은 직접 경험, 일관된 주제, 진정성, 읽기 쉬운 구조, 최신성입니다. 케어드의 일지형 콘텐츠와 방향이 같습니다.

### 키워드 묶음

검색량은 확인하지 못했습니다. 발행 전에 네이버 검색광고 도구로 확인합니다.

| 묶음 | 예시 |
|---|---|
| 고민 | 속건조 세럼, 민감성 세럼, 환절기 피부 건조 |
| 성분 | 오트 세럼, 콜로이달 오트밀, 엑토인 세럼, PDRN 세럼 민감성 |
| 비교 | 시카 오트 차이, 민감성 토너 고르는 법 |
| 브랜드 | 케어드 세럼, 케어드 오트 토너, 케어드 후기 |

### 체험단 운영

- 민감 피부 경험이 있는 사람을 우선합니다.
- 최소 사용 기간을 2주로 잡습니다. **[작업 기본값]**
- 같은 문구를 나눠 주지 않습니다. 유사문서를 피하기 위해 **핵심 정보만 주고 글은 각자 씁니다.**
- 사진을 공유하지 않습니다.
- 블로거에게 효능 수치를 넣으라고 요청하지 않습니다.

### 제목 예시

공백 포함 15~25자, 키워드는 앞쪽에 둡니다.

```text
속건조 세럼, 오트 성분 고를 때 볼 것
민감성 토너 고르는 기준 3가지
```

## 4. 쇼핑라이브

- 라이브의 핵심은 **질문에 답하는 시간**입니다.
- 진행자가 시험 조건 없는 수치를 말하지 않게 대본을 미리 검토합니다.
- 흔들어 쓰는 세럼 제형을 화면 가까이 보여 줍니다.
- 민감 피부 질문에는 `피부마다 다를 수 있어요`로 답하고, 패치 테스트를 안내합니다.

## 5. 올리브영 매장

- 공개 자료의 입점 제품은 PDRN 오트밀크 세럼입니다. 다른 제품의 입점 여부는 브랜드에 확인합니다.
- 매장 소재의 첫 문구는 성분이 아니라 고민으로 시작합니다.
- 10mL 소용량이 매장에서 판매되는지 확인합니다. 민감 피부 고객의 첫 구매 장벽을 낮출 수 있습니다. **[해석]**
- 온라인 콘텐츠에 올리브영을 언급할 때는 `전국 주요 오프라인 23개 매장`까지만 씁니다. `전국 올리브영 입점`이라고 쓰지 않습니다.

## 6. 틱톡과 아마존 US

- **주인공은 오트입니다.** 해외에서는 시카 다음 대안보다 `oat`, `oatmeal`, `sensitive skin`, `barrier`처럼 바로 이해되는 말로 소개합니다. **[해석]**
- **첫 장면:** 흔들어 층이 섞이는 세럼을 보여 줍니다.
- **크리에이터:** 공식 모집 폼으로 들어온 사람 중 민감 피부 경험을 보여 줄 수 있는 사람을 우선합니다.
- **링크:** 영상에서 아마존 공식 스토어로 연결합니다. 스토어 후기의 평점과 연결 지표를 함께 봅니다.
- **표현:** 국내 금지선을 해외에도 그대로 적용합니다. 미국의 표시 규칙(FTC)과 화장품 표현 규제는 이번에 확인하지 못했습니다. 영어 소재는 현지 검수 후 게시합니다.

## 7. 인스타그램과 스레드

| 채널 | 내용 | 형식 |
|---|---|---|
| 인스타그램 | 저널 요약, 2주 피부 일지, 루틴 순서 | 카드뉴스, 릴스 |
| 스레드 | `요즘 피부 어때요?` 같은 짧은 질문, 일지 한 줄 | 글 |

스레드 답글에서 나온 표현은 블로그 키워드와 콘텐츠 주제로 옮깁니다. 답글의 피부 고민은 진단하지 않고, 필요하면 전문의 상담을 권합니다.

## 8. 광고 표시 규칙

공정위 추천·보증 지침을 다룬 기사와 해설을 정리했습니다. **최신 개정은 공정위 원문으로 확인해야 합니다.**

| 항목 | 기준 |
|---|---|
| 표시 대상 | 현금, 제품 제공, 할인, 협찬 등 경제적 이해관계 전부 |
| 블로그, 캡션 | 본문 첫 부분이나 첫 번째 해시태그 |
| 영상 전체가 추천일 때 | 시작과 끝에 넣고 영상 중 반복 표시 |
| 안 되는 위치 | `더보기` 뒤, 게시물 중간, 댓글, 별도 페이지 |
| 쓸 수 있는 말 | `협찬`, `광고`, `유료 광고`, `광고비 지급` |
| 쓸 수 없는 말 | `sponsored`, `partner`, `thanks to`, `Collaboration` |

숏폼에 직접 적용되는 세부 기준은 찾지 못했습니다. 작업 기준으로 영상 전체에 `협찬` 자막을 고정하고, 캡션 첫 줄에도 표시합니다. **[작업 기본값]**

## 9. 화장품 표현 심의

식약처는 숏폼의 자극적인 체험 후기를 집중 점검하고 있다고 전해지며, 의약품 오인 광고 적발도 계속 보도되고 있습니다.

케어드는 민감 피부와 PDRN을 다뤄서 표현 위험이 큰 편입니다. **[해석]** 그래서 아래 절차를 둡니다.

1. 크리에이터에게 금지선을 먼저 전달합니다.
2. 대가가 있는 콘텐츠는 게시 전에 초안을 받습니다.
3. 수치를 쓰려면 시험기관, 기간, 대상자수를 함께 확인합니다.
4. 광고 소재는 식약처 `화장품 표시·광고 가이드라인` 최신본과 대조합니다.

## 10. 크리에이터 브리프 양식

아래는 간단한 요약 양식입니다. 실제 발송은 `guide-naver-blog.md`, `guide-shortform.md`를 씁니다.

```text
[기본 정보]
업로드 기한:
협업 형식:
제공 제품:
최소 사용 기간:
표시 문구:

[이번 콘텐츠의 한 문장]
(예: 시카 다음으로 살펴보는 오트 루틴)

[꼭 담을 것 4가지]
1. 나의 피부 타입과 평소 고민
2. 실제 사용 기간과 사용 순서
3. 실제 느낀 점과 아쉬운 점
4. 패치 테스트 안내

[자유롭게 해 주세요]
촬영 장소, 편집, 말투, 일상 이야기

[쓰지 말아 주세요]
치료 / 재생 / 복원 / 염증 / 아토피 / 시술 효과 / 스킨부스터 / 다른 제품 비교
시험 조건 없는 수치 / 트러블이나 홍조가 없어졌다는 단정

[확인 일정]
초안 제출일:
수정 회신일:
게시물 유지 기간:
```

## 11. 발행 전 점검표

- [ ] 이 채널의 역할에 맞는 콘텐츠인가
- [ ] 표시 문구가 시작, 끝, 본문 첫 부분에 있는가
- [ ] 실제 사용 기간이 적혀 있는가
- [ ] 금지 표현과 시험 조건 없는 수치가 없는가
- [ ] 패치 테스트 안내가 있는가
- [ ] 세럼 용량, 크림 함량과 출시일을 브랜드에 확인했는가
- [ ] 블로그라면 `guides/seo-guide.md`의 점검표를 통과했는가
- [ ] 영어 소재는 현지 검수를 거쳤는가
