# 케어드(kared) 문체 가이드

확인일: 2026-11-02

이 파일은 케어드의 콘텐츠를 쓸 때 지킬 **브랜드 말투와 제품 표현 기준**입니다.
어느 채널에 어떻게 올릴지는 같은 폴더의 `channel-guide.md`를 따릅니다.

> **이 가이드의 범위:** 공식몰, 보도자료, 리뷰 플랫폼의 공개 자료로 만들었습니다.
> 공식몰 About 페이지는 이미지로만 되어 있어 내용을 읽지 못했습니다. 브랜드 철학 원문을 받으면 1절을 보완합니다.

### 근거 등급

| 등급 | 뜻 |
|---|---|
| **[공식]** | 케어드 공식몰, 공식 링크 페이지에 표기된 내용 |
| **[보도]** | 언론 기사에 실린 내용. 보도자료 기반일 수 있음 |
| **[리뷰]** | 소비자 후기에서 읽은 경향. 효능 근거로 쓰지 않음 |
| **[해석]** | 공개 자료를 바탕으로 이 가이드가 내린 판단 |
| **[작업 기본값]** | 판단 기준이 필요해서 정한 값. 검증된 수치가 아님 |

## 1. 브랜드 방향성

**한 줄 정의:** 민감한 피부에 필요한 영양을 고루 채운다는 `스킨 뉴트리션`을 차분하게 설명하는 웰니스 스킨케어. **[해석]**

| 항목 | 내용 | 등급 |
|---|---|---|
| 슬로건 | `민감성 피부를 위한 웰니스 스킨케어` | [공식] |
| 소개 | `민감 피부가 편안해지는 피부 영양 솔루션` | [공식] |
| 현재 방향 | 시카 다음 선택지로 오트를 제안, 진정에 그치지 않는 `스킨 뉴트리션` | [보도] |
| 제품 구조 | 토너, 세럼, 크림으로 이어지는 오트 기반 제품군 | [보도] |
| 글로벌 | 세럼 용량과 패키지를 글로벌 시장에 맞춰 확장. 올리브영 `NEXT 글로벌 K-뷰티 BEST` 선정 | [보도] |

### 케어드만의 차별점 **[해석]**

경쟁 민감 피부 브랜드가 성분을 말할 때, 케어드는 **왜 피부가 그런 상태인지**부터 말합니다. 공식 저널이 `'왜'를 알면 쉬워지는 스킨-케어`라는 이름으로 원인, 고민, 생활 습관을 나눠 다루고 있기 때문입니다.

| 축 | 질문 | 내용 |
|---|---|---|
| **Why** | 왜 불편한가 | 속건조, 컨디션, 계절, 생활 습관 |
| **What** | 무엇을 채우는가 | 오트, 수분, 유분, 단백질 |
| **Routine** | 어떻게 쓰는가 | 토너 → 세럼 → 크림, 레이어링 |

모든 콘텐츠는 **Why → What → Routine** 순서로 씁니다.

## 2. 가장 먼저 할 일: 모드 고르기

| | **모드 J: 피부 일지형** (기본값) | **모드 S: 성분 설명형** |
|---|---|---|
| 언제 | 실제 사용 기간과 피부 반응이 있을 때 | 제품 정보, 성분, 루틴을 설명할 때 |
| 중심 | 내 피부 상태와 사용 기간 | 성분의 역할과 고르는 기준 |
| 첫 문장 | `요즘 ~`로 고민을 말함 | 독자의 고민을 짚고 기준을 제시 |
| 주된 종결 | `~었어요`, `~더라고요` | `~이에요`, `~는데요.` |
| 문장 | 길고 이어지는 문장 | 짧고 끊어지는 문장 |
| 이모지 | 쓰지 않음. 끝에 `:)` 한 번 허용 | 소제목마다 1개 이하 |

**경험을 지어내지 마세요.** 민감 피부 콘텐츠의 신뢰는 경험에서 나옵니다. 사용 기간, 피부 타입, 피부 반응을 받지 못했다면 모드 S로 씁니다.

## 3. 공통 말투

### 문체 한 줄 요약

**차분하고 다정한 해요체로, 불안을 키우지 않고 "왜 그런지"를 설명하는 문체.**

- 피부 전문가처럼 가르치지 않습니다. 먼저 공부해 본 사람이 알려 주는 말투입니다.
- 고민을 과장하지 않습니다. `피부가 망가졌어요`보다 `요즘 컨디션이 들쭉날쭉해요`처럼 씁니다.
- 결론을 강요하지 않습니다. `피부마다 다를 수 있어요`를 자연스럽게 넣습니다.

### 지켜야 할 규칙

- 본문은 해요체로 씁니다.
- `ㅎㅎ`, `ㅋㅋ`, `ㅠㅠ`, `~~`, 느낌표 연속은 쓰지 않습니다.
- 공포를 주는 표현을 쓰지 않습니다. (`이거 안 하면 피부 늙어요`)
- 시카를 포함한 다른 성분이나 제품을 깎아내리지 않습니다. 오트는 `또 다른 선택지`로 말합니다.
- 패치 테스트 안내를 민감 피부 콘텐츠의 기본 문장으로 넣습니다.

### 즐겨 쓸 어휘

| 분류 | 어휘 |
|---|---|
| 상태 | 속건조, 컨디션, 푸석한, 예민해진, 환절기 |
| 사용감 | 편안하게, 촉촉하게, 산뜻하게, 부드럽게 감싸는 |
| 브랜드 | 스킨 뉴트리션, 영양, 균형, 오트, 데일리, 루틴 |
| 습관 | 수면, 식습관, 스트레스, 선 케어 |
| 설명 | 왜, 그래서, 고르는 기준, 먼저 살펴볼 것 |

### 쓰지 말 것

아래는 작성 기준입니다. **[작업 기본값]** 식약처 가이드라인 원문과 대조한 목록이 아니므로, 광고 소재는 법무 또는 심의 담당의 확인을 거칩니다.

| 쓰지 말 것 | 이유 | 이렇게 쓰기 |
|---|---|---|
| `치료`, `항염`, `염증 완화`, `아토피` | 의약품 오인 우려 | `피부가 편안하게 느껴졌어요.` |
| `재생`, `복원`, `회복` | 의약품 오인 우려. 공식 카피의 `장벽 복원`도 그대로 옮기지 않음 | `수분과 장벽 관리에 초점을 맞춘 크림이에요.` |
| `홍조가 사라져요`, `트러블이 없어졌어요` | 효능 단정 | `제 피부에는 자극 없이 사용했어요.` (실제 경험일 때만) |
| `시술 같은`, `스킨부스터`, `주사` | 시술 효과로 오인. PDRN 콘텐츠에서 특히 주의 | `PDRN 성분을 담은 세럼이에요.` |
| `민감 피부 100% 안전`, `무자극` | 근거 없는 단정 | `민감 피부를 위해 만든 제품으로 소개하고 있어요.` |
| `15배 진정`, `광채 +107%`, `30층 수분 충전` | 공식 수치라도 크리에이터 콘텐츠에서 조건 없이 쓰면 오해 우려. `광채 +107%`는 상세 이미지 각주에 한국피부과학연구원, 22명, 2025.09.12~10.02 표기가 있고, `15배`와 `30층`은 각주를 확인하지 못함 | 브랜드가 승인한 각주와 함께만 사용 |
| `FDA 인증`, `FDA 승인` | 보도 표현은 콜로이달 오트밀 성분의 등재이며, 제품 승인과 다름 | 쓰지 않음. 필요하면 성분 단위로 정확히 서술 |
| `인생템`, `강추`, `무조건` | 브랜드의 차분한 톤과 맞지 않음 | 경험이나 기준으로 대체 |

## 4. 제품별 표현 카드

가격은 2026-11-02 공식몰 표기 기준이며, 할인가는 수시로 바뀝니다.

### PDRN 오트밀크 세럼

| 항목 | 내용 |
|---|---|
| 정보 | 정가 35,000원, 할인가 29,800원, 10mL 13,000원 **[공식]** |
| 역할 | 브랜드 베스트셀러, 라인의 중심 **[보도]** |
| 제형 | 세럼처럼 가볍게 흡수되고 크림처럼 부드럽게 감싸는 듀얼 레이어 **[보도]** |
| 주요 성분 | 콜로이달오트밀, 귀리커넬오일, 엑토인, 시카 PDRN **[보도]** |
| 사용법 | 상하로 흔든 뒤 1~3펌프, 피부결을 따라 롤링 **[공식]** |
| 콘텐츠 포인트 | 흔들어 쓰는 장면이 영상 소재가 됨 **[해석]** |
| 정직한 단서 | 공식몰 후기 표본이 작음 |

**확인 필요**

- 용량: 공식 릴스(2026-10-07)와 제품명은 35ml입니다. 다만 상세 사양표는 50ml이고, 아마존과 스타일코리안 판매분도 50ml입니다. 국내 가이드는 35ml로 쓰고 브랜드에 확정을 받습니다.
- PDRN 표기: 공식몰 전성분에서 `PDRN`이 아니라 `소듐디엔에이`가 보입니다. 성분 설명 글을 쓸 때 어떤 원료를 뜻하는지 확인합니다.

### 오트 바이옴 수딩 토너

| 항목 | 내용 |
|---|---|
| 정보 | 정가 28,000원, 할인가 21,000원. 신상품 **[공식]** |
| 역할 | 세안 직후 수분 공급과 밸런싱 **[보도]** |
| 주요 성분 | 국내산 귀리씨수, 특허 유산균 엑소좀, 징크 PCA **[보도]** |
| 쓰지 말 것 | `피지는 줄이고`, `30층 수분 충전`은 시험 자료 확인 전 사용 금지 |

### 오트 프로틴 베리어 젤 크림

| 항목 | 내용 |
|---|---|
| 정보 | 50ml, 34,000원. COMING SOON **[공식]**, 11월 출시 예정 안내 **[공식]** |
| 역할 | 젤처럼 가볍게 스며드는 수분, 장벽 관리 크림 **[보도]** |
| 주요 성분 | 오트 프로틴, 13종 펩타이드, 판테놀 **[보도]** |

**확인 필요**

- 함량: 공식 카피의 `10% 귀리 단백질`과 공식 릴스의 `오트 단백질 100,000ppm`은 일치하지만, 상세 성분 표기는 `귀리단백질추출물 10,000ppm`입니다. 확인 전에는 함량을 적지 않습니다.
- 출시일: 정확한 날짜를 확인한 뒤 발행합니다. 출시 전에는 후기형 콘텐츠를 쓰지 않습니다.

### 양배추 파이버 모공 리셋 클렌저

| 항목 | 내용 |
|---|---|
| 정보 | 네이버 브랜드스토어 판매 **[공식]** |
| 소비자 언어 | 거품이 풍성하고 부드러움, 스크럽 알갱이가 없음 **[리뷰]** |
| 정직한 단서 | 양배추 냄새가 강하다는 후기가 있음 **[리뷰]** |
| 쓰지 말 것 | `피지 분비율 개선`은 시험 자료 확인 전 사용 금지 |

### 그 외

화해에서 `Defense Volume Lip Shield`가 확인됩니다. 한글 제품명, 가격, 현재 판매 여부를 확인하지 못했으므로 자료를 받기 전에는 쓰지 않습니다.

## 5. 구조

### 모드 J: 피부 일지형

**제목:** `제품명, 상황 + 사용 기간 + 후기`

```text
케어드 PDRN 오트밀크 세럼, 환절기 속건조에 [실제 기간] 써본 후기
```

1. 요즘 피부 상태 (Why)
2. 나의 피부 타입과 기준
3. 제품을 고른 이유 (What)
4. 사용 순서와 사용감 (Routine)
5. 사용 기간별 변화. 느낌만 적고 효능처럼 단정하지 않음
6. 아쉬운 점 한 가지
7. 맞을 것 같은 분
8. 패치 테스트 안내

### 모드 S: 성분 설명형

**제목:** `고민 키워드 + 고르는 기준`

```text
속건조 세럼, 오트 성분으로 고를 때 볼 것
```

1. 고민이 생기는 맥락을 짚기 (Why)
2. 성분이 하는 역할을 쉽게 설명 (What)
3. 시카와 오트의 차이를 비방 없이 설명
4. 어떤 순서로 쓰는지 (Routine)
5. 생활 습관 한 가지를 함께 제안
6. 제품 안내와 패치 테스트 안내

### 생활 습관 문장 쓰는 법

공식 저널은 식습관, 수면 습관, 스트레스, 선 케어를 다룹니다. 케어드의 강점이지만 건강 정보이므로 조심해서 씁니다.

| 쓰지 말 것 | 이렇게 쓰기 |
|---|---|
| `당을 줄이면 피부가 밝아져요.` | `저는 요즘 단 음식을 줄이면서 피부 컨디션도 함께 살펴보고 있어요.` |
| `우유가 트러블의 원인이에요.` | `먹는 음식과 피부 컨디션을 함께 기록해 보는 분도 있어요.` |

의학적 내용은 출처를 밝히고, 개인차를 적습니다.

## 6. 작성 후 점검표

**공통**

- [ ] Why → What → Routine 순서인가
- [ ] 표시 문구가 채널 기준에 맞는 위치에 있는가
- [ ] 치료, 재생, 복원, 염증, 시술 표현이 없는가
- [ ] 시험 조건 없는 수치가 없는가
- [ ] 시카나 다른 제품을 깎아내리지 않았는가
- [ ] 공포를 주는 표현이 없는가
- [ ] 패치 테스트 안내가 있는가
- [ ] 세럼 용량과 크림 함량이 확인된 값인가

**모드 J**

- [ ] 실제 사용 기간과 피부 타입이 있는가
- [ ] 아쉬운 점이 한 가지 이상 있는가
- [ ] 느낌과 효능을 구분했는가

**모드 S**

- [ ] 성분 설명에 출처가 있는가
- [ ] 생활 습관 문장이 단정하지 않는가
- [ ] 제품 소개가 정보보다 앞서지 않는가

## 7. 적용 예시

아래는 문체를 보여 주는 **틀**입니다. 대괄호 안은 실제 사용 내용으로 채웁니다.

### 모드 J

```text
#협찬 #제품제공

요즘 [실제 계절이나 상황] 때문인지 피부 겉은 괜찮은데 속이 건조한 느낌이 들더라고요.
```
