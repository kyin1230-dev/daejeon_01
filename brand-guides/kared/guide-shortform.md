## 4. 콘텐츠 컨셉

아래 3가지 중 하나를 골라 주세요.

| 컨셉 | 첫 장면 | 전개 |
|---|---|---|
| **A. 흔들면 섞여요** | 층이 나뉜 세럼을 흔드는 근접 컷 | 제형 → 바르기 → 사용감 한마디 |
| **B. 예민한 날의 루틴** | 요즘 피부 고민 한마디 | 세안 → 세럼 → 마무리 |
| **C. 7일 피부 일지** | `1일 차` 자막 | 날짜별 짧은 사용 장면 → 느낀 점 |

**구성 예시 (20~40초)**

| 구간 | 내용 |
|---|---|
| 0~3초 | 흔드는 장면 또는 고민 한마디 |
| 3~20초 | 제형과 바르는 장면 |
| 20~35초 | 실제로 느낀 사용감 |
| 35~40초 | 제품명과 구매처 안내 |
